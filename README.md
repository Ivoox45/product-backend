# 📦 Product Backend API

A Spring Boot REST API for managing products and categories with security, validation, and documentation.

## 🚀 Tech Stack

- Java 21
- Spring Boot 3.5
- Spring Security + JWT
- Spring Data JPA + MySQL
- Bean Validation (Jakarta)
- Swagger / OpenAPI (SpringDoc)
- MapStruct
- Maven

## 🛠️ Running the Project

```bash
# 1. Clone the repo
git clone https://github.com/Ivoox45/product-backend.git
cd product-backend

# 2. Run the app
./mvnw spring-boot:run
